# ИИ-помощник MoliyaHub

Чат-помощник в правом нижнем углу всех страниц сайта (ru / uz / en). Отвечает
на вопросы предпринимателей по данным самого сайта и считает цифры тем же
кодом, что и страницы «Анализ» и «Финансирование».

## Как это устроено

```
Браузер (components/assistant/assistant-widget.tsx)
   │  POST /api/assistant  {messages, locale, page}
   ▼
app/api/assistant/route.ts ── лимит запросов, проверка ввода, журнал
   ▼
lib/assistant/chat.ts ── Gemini (тот же GEMINI_API_KEY, что у ИИ-анализа)
   │  модель сама вызывает инструменты ↓
   ▼
lib/assistant/tools.ts
   ├─ search_knowledge        → lib/assistant/knowledge.ts (база знаний)
   ├─ search_financing        → каталог OFFERS + ставки из админки + bank.uz
   ├─ calculate_scoring       → lib/finance/ratios.ts (методика сайта)
   ├─ calculate_loan_payment  → buildRepaymentSchedule()
   ├─ search_projects         → Биржа проектов (Supabase + демо)
   ├─ get_cbu_data            → курсы и основная ставка ЦБ РУз
   └─ get_my_latest_analysis  → последний анализ пользователя (если вошёл)
```

Главный принцип (зашит в `lib/assistant/prompt.ts`): ставки, суммы, условия,
проекты и сведения о сайте модель берёт **только из инструментов**. Если
данных нет — честно говорит и отправляет к источнику или к команде.

## База знаний — откуда данные

Всё собирается автоматически из уже существующих файлов сайта: поменяли
текст на сайте — помощник знает новую версию после деплоя.

| Что знает помощник | Источник в коде |
|---|---|
| FAQ главной | `i18n/dictionaries/*.ts` → `home.faq` |
| Исламский гид: мурабаха, иджара, мушарака, мудараба | `islamicGuide` |
| 16 советов предпринимателям | `advicePage.tips` |
| Консалтинг, команда, партнёры | `consulting`, `about`, `lib/data/partners.ts` |
| Описание разделов сайта | `analyze`, `financing`, `projectsIndex`, `businessPlans`, `businessPlanAi` |
| 11 продуктов финансирования | `lib/data/banks.ts` → `OFFERS` (+ ставки из админки) |
| Реальные бизнес-кредиты банков | таблица `bank_credit_offers` (ежедневный скрейпер bank.uz) |
| Реестр банков Узбекистана | `BANK_DIRECTORY` |
| 11 отраслей, образцы ТЭО, точка безубыточности, окупаемость | `lib/data/industries.ts`, `lib/data/business-plan-samples.ts` |
| Проекты на бирже | таблица `projects` + `SEED_PROJECTS` |
| Курсы валют и основная ставка ЦБ | `app/api/cbu-rates`, `app/api/cbu-refinancing-rate` |
| Официальные источники (soliq.uz, lex.uz, cbu.uz, my.gov.uz, trk.uz) | `lib/assistant/custom-knowledge.ts` |

### Как добавить новые знания

Сведения, которых нет на страницах сайта (налоговые режимы и ставки, льготы
МСБ, госпрограммы, требования банков к документам), добавляются в
`lib/assistant/custom-knowledge.ts` — там есть шаблон записи. Правила:
только проверенные данные, с источником и датой в тексте, на трёх языках.

## Запуск

1. **Ключ.** Используется уже настроенный в Vercel `GEMINI_API_KEY` — новый
   ключ не нужен. Без ключа виджет вежливо предлагает написать на
   info@moliyahub.uz.
2. **Журнал и оценки (рекомендуется).** Выполнить `docs/sql/assistant.sql`
   в Supabase → SQL Editor. После этого вопросы, ответы и оценки 👍/👎
   сохраняются в `assistant_logs`. Без таблицы помощник тоже работает.
3. **Деплой** — обычный, через Vercel.

## Контроль качества

- Раз в неделю смотреть ответы с оценкой 👎 (запрос есть в
  `docs/sql/assistant.sql`) и дополнять базу знаний.
- Перед запуском прогнать вопросы из списка ниже на трёх языках и проверить,
  что цифры совпадают с сайтом, а ссылки открываются.

Контрольные вопросы:
1. Где взять 500 млн сум на оборудование? → продукты из каталога, ставки как на /financing
2. Чем мурабаха отличается от кредита? → по Исламскому гиду
3. Выручка 2 млрд, прибыль 150 млн, оборотные активы 900 млн, текущие долги 520 млн → коэффициенты без выдуманного балла, просьба дать активы и капитал
4. Посчитай платёж: 300 млн на 36 месяцев под 22% → ~11,46 млн/мес
5. Какой курс доллара сегодня? Какая ставка ЦБ? → данные cbu.uz
6. Есть ли проекты в Самарканде? → «Экспорт керамики и сувениров»
7. Какой у меня был балл? (вошедший пользователь) → из кабинета
8. Какая ставка НДС? → общее объяснение + отсылка к soliq.uz, без выдуманной цифры
9. Напиши стихотворение → вежливый отказ, только бизнес и финансы
10. Murobaha nima? / What is ijara? → ответ на языке вопроса

## Ограничения текущей версии

- Бесплатный тариф Gemini: при пиковой нагрузке Google возможны отказы —
  тогда помощник предлагает повторить через минуту (есть повтор и запасная
  модель).
- Лимит — 20 вопросов за 10 минут с одного IP, в памяти функции (мягкая
  защита; для строгого лимита — Upstash/Redis или таблица в Supabase).
- История диалога хранится только в браузере посетителя (sessionStorage).
- Персональные данные: промпт запрещает модели запрашивать ФИО, ИНН,
  паспорт и номера счетов; в модель уходят только текст вопроса и цифры.
